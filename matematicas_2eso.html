✏️ Ejemplos del mundo real

🚗 Ejemplo 1 — Ruedas de coches

Cada coche tiene 4 ruedas. Si hay x coches: 4x ruedas.

🧒 Ejemplo 2 — Edades

El padre tiene el triple de edad que el hijo. Si el hijo tiene h años:

Padre → 3h años.

💶 Ejemplo 3 — Dinero

Luis gastó 4€ más que Loli. Si Loli gastó x euros:

Luis → x + 4 euros. Entre los dos → x + (x+4) = 2x + 4 euros.

📏 Ejemplo 4 — Triángulo isósceles

El lado desigual es la mitad de cada lado igual. Si los lados iguales miden a:

Lado desigual → a/2. Perímetro → 2a + a/2.

🔗 Monomios Semejantes

Dos monomios son semejantes si tienen exactamente la misma parte literal (mismas variables con mismos exponentes).

✅ Son semejantes — ¡se pueden sumar/restar!

3x² y −5x² → misma parte literal x² → 3x² − 5x² = −2x²

4xy y 7xy → misma parte literal xy → 4xy + 7xy = 11xy

❌ No son semejantes — ¡NO se pueden sumar!

3x² y −5x³ → distinto exponente de x

4xy y 7x²y → distinta parte literal

⚠️ Solo puedes sumar o restar monomios semejantes. ¡Es como sumar manzanas con manzanas, nunca con naranjas!

➕ Ecuaciones de 1er Grado

Una ecuación de primer grado tiene la forma ax + b = c. El objetivo es encontrar el valor de x.

ax + b = c

⚖️ Reglas de oro

⚖️ Lo que hagas a un lado de la ecuación, debes hacerlo al otro
🔄 Los términos cambian de signo al pasar al otro lado del igual
🎯 Agrupa las x a un lado y los números al otro

✏️ Simple · Ejemplo: 7x + 9 = 3 + 9x

1

Pasamos las x a la izquierda y los números a la derecha:

7x − 9x = 3 − 9
2

Operamos en cada lado:

−2x = −6
3

Dividimos ambos lados por −2:

x = (−6) ÷ (−2) = 3
✅ x = 3
🔍 Comprobación: 7(3)+9 = 30 ✓ y 3+9(3) = 30 ✓

🔧 Con paréntesis · Ejemplo: 2(x−2) = −(4−x)

1

Aplicamos la propiedad distributiva:

2x − 4 = −4 + x
2

Agrupamos términos:

2x − x = −4 + 4
3
x = 0
✅ x = 0

➗ Con fracciones · Ejemplo: (3/2)x + 8 = (3/5)x − 1

1

Multiplicamos todo por el mcm de los denominadores:

mcm(2, 5) = 10

15x + 80 = 6x − 10
2
15x − 6x = −10 − 80  →  9x = −90
3
x = −90 / 9 = −10
✅ x = −10

🧩 Problema resuelto

📌 Las edades de dos hermanos suman 38 años. Uno es 8 años mayor que el otro.

Llamamos x a la edad del menor. El mayor tiene x + 8.

x + (x + 8) = 38  →  2x = 30  →  x = 15

El menor tiene 15 años y el mayor 23 años.

² Ecuaciones de 2º Grado

Tienen la forma ax² + bx + c = 0 (con a ≠ 0). Pueden tener 0, 1 ó 2 soluciones.

ax² + bx + c = 0

📐 Fórmula general (la cuadrática)

x = −b  ±  √b² − 4ac 2a
¿Cómo se usa?
Identifica a, b y c en tu ecuación, sustitúyelos en la fórmula y calcula las dos opciones (+ y −).

El Discriminante Δ = b² − 4ac

Δ > 0
✅ 2 soluciones reales
Δ = 0
⭕ 1 solución (doble)
Δ < 0
❌ Sin solución real

✏️ Completa · Ejemplo: x² − 7x + 12 = 0

a =1
b =−7
c =12
1

Calculamos el discriminante:

Δ = (−7)² − 4·1·12 = 49 − 48 = 1

Δ > 0 → 2 soluciones

2

Aplicamos la fórmula:

x = 7  ±  √1 2  =  7 ± 1 2
3

Calculamos las dos soluciones:

Solución +
7 + 1 2 = 4
Solución −
7 − 1 2 = 3
✅ x₁ = 4    x₂ = 3

⚡ Incompletas — sin fórmula

Tipo 1: ax² + c = 0  (falta bx)

📌 x² − 1 = 0

x² = 1 → x = ±√1 → x₁ = 1, x₂ = −1

📌 4x² − 9 = 0

4x² = 9 → x² = 9/4 → x = ±3/2 → x₁ = 3/2, x₂ = −3/2

Tipo 2: ax² + bx = 0  (falta c)

📌 x² + 2x = 0

Factor común x:  x·(x + 2) = 0

x = 0  ó  x + 2 = 0 → x₁ = 0, x₂ = −2

📌 6x² + 42x = 0

6x·(x + 7) = 0 → x₁ = 0, x₂ = −7

📌 2x² = 0

x² = 0 → x = 0 (solución doble)
