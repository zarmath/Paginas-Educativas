💡 Trucos para el Examen

Los atajos más útiles para identificar cada función sintáctica.

🎯
Sujeto
¿Quién + verbo?
El verbo siempre concuerda con el sujeto.

Con verbos tipo gustar: el sujeto es lo que gusta, no quien lo experimenta.

"Me gusta la fruta" → sujeto: "la fruta"
📦
CD — Complemento Directo
¿Qué + verbo?
Sustitución: lo / la / los / las

"Compré el libro" → "Lo compré" ✅

Si la sustitución no funciona, no es CD.
👤
CI — Complemento Indirecto
¿A quién / Para quién + verbo?
Sustitución: le / les

"Di el libro a Juan" → "Le di el libro" ✅

Cuando CD + CI juntos: le + lo → se lo
🔵
Atributo
Verbo COPULATIVO obligatorio:
ser / estar / parecer

Sustitución: lo
"Parece inteligente" → "Lo parece" ✅

⚠️ "Estar en casa" NO es copulativo (es lugar).
🟠
Complemento Predicativo
Verbo NO copulativo.
Concuerda en género y número con el sujeto.

"Las atletas llegaron cansadas" → si cambia el sujeto, cambia "cansadas"

Si concuerda = CPred. Si no concuerda = CC de Modo.
🔄
Voz Pasiva
Estructura: sujeto paciente + ser + participio + por + C.Agente

"Pedro compró el libro"
→ "El libro fue comprado por Pedro"

El C. Agente siempre empieza por "por".
🧬
Parasíntesis
Prefijo + raíz + sufijo a la vez.

Test: si quitas el prefijo O el sufijo, ¿existe la palabra?

"abaratar" → ¿"abarato"? ❌ ¿"baratar"? ❌ → PARASÍNTESIS
"desobedecer" → "obedecer" ✅ → PREFIJACIÓN
🧩
Tipos de CC
Tiempo: ¿Cuándo? → "ayer", "el martes"
Lugar: ¿Dónde? → "en el parque"
Modo: ¿Cómo? → "con cuidado"
Causa: ¿Por qué? → "por el tráfico"
Instrumento: ¿Con qué? → "con un cuchillo"
Compañía: ¿Con quién? → "con mi hermano"
