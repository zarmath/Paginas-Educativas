1 ¿Qué es una ecuación?
Una ecuación es una igualdad entre dos expresiones que contiene una o varias incógnitas (letras cuyo valor no conocemos).

Resolver una ecuación significa encontrar el valor de la incógnita que hace la igualdad verdadera. A ese valor se le llama solución.
3x + 1 = 9 − x  →  x = 2 ✓
MiembrosLo que hay a la izquierda y derecha del signo =
TérminosLos sumandos que forman cada miembro
IncógnitaLa letra que queremos encontrar (normalmente x)
GradoEl mayor exponente de la incógnita en la ecuación
2 Transposición de términos
La idea clave: lo que hacemos a un lado lo hacemos al otro. Así la ecuación sigue siendo equivalente (misma solución).
➕ Caso 1: x + a = b ▼
El número que suma en un lado, pasa restando al otro.
x + 3 = 7  →  x = 7 − 3  →  x = 4
➖ Caso 2: x − a = b ▼
El número que resta en un lado, pasa sumando al otro.
x − 5 = 3  →  x = 3 + 5  →  x = 8
✖️ Caso 3: a·x = b ▼
El número que multiplica, pasa dividiendo al otro.
4x = 20  →  x = 20 ÷ 4  →  x = 5
➗ Caso 4: x/a = b ▼
El número que divide, pasa multiplicando al otro.
x/3 = 4  →  x = 4 · 3  →  x = 12
3 Resolver ecuaciones de 1er grado
Pasos para resolver cualquier ecuación de primer grado:
1. Quitar paréntesis (distributiva)
2. Quitar denominadores (multiplicar por el m.c.m.)
3. Pasar términos con x a un lado, números al otro
4. Reducir y despejar x
Ejemplo completo:
▶3x − 8 = 4
▶3x = 4 + 8   (transponer el −8)
▶3x = 12
▶x = 12/3 = 4 ✓
Con paréntesis:
▶5x − 2(2x − 2) = 8 − (3 + 2x)
▶5x − 4x + 4 = 8 − 3 − 2x
▶x + 4 = 5 − 2x
▶3x = 1 → x = 1/3 ✓
Con denominadores (m.c.m. = 20):
▶x/4 + 2/5 = 1 + x/10
▶5x + 8 = 20 + 2x
▶3x = 12 → x = 4 ✓
4 Ecuaciones de 2º grado
Tienen la forma general: ax² + bx + c = 0
Pueden tener 2 soluciones, 1 solución doble, o ninguna.
x = (−b ± √(b²−4ac)) / 2a
📌 Tipo 1: ax² + c = 0 ▼
Despejamos x²:
2x² − 18 = 0 → x² = 9 → x = ±3
📌 Tipo 2: ax² + bx = 0 ▼
Factor común con x:
x² − 5x = 0 → x(x−5) = 0 → x=0 o x=5
📌 Tipo 3: ax² + bx + c = 0 (fórmula) ▼
Ejemplo: 5x² − 7x + 2 = 0 → a=5, b=−7, c=2
x = (7 ± √(49−40)) / 10 = (7±3)/10
→ x₁ = 10/10 = 1    x₂ = 4/10 = 2/5
💡 Tipos especiales
Infinitas solucionesSi al resolver te queda 0 = 0
Sin soluciónSi al resolver te queda 0 = 5 (imposible)
